# 千秋图 · 古风历史舆图

一个面向未成年人学历史的古风历史事件 GIS：界面如一幅装裱好的古画，
按年份浏览中国史与世界史事件。

**在线访问**：<https://jerryliuxa.github.io/history/>（GitHub Pages，push 到 main 自动部署）

## 运行

零构建、零依赖，**直接双击 `index.html`** 即可在浏览器中打开（file:// 可用）。

也可以本地起服务：

```bash
python -m http.server 8917
# 打开 http://127.0.0.1:8917/
```

单文件版（全部内联，方便分发）：`python -I tools/build_single.py <输出路径>`

## 功能（v1）

- **古风舆图**：Natural Earth 110m 真实海岸线水墨化（无现代国界），宣纸纹理、
  墨晕边缘、装裱边框全部由 SVG/CSS 生成，无图片资源。
- **卷轴时间轴**（公元前3000 ~ 公元1949）：**滚轮缩放**（以鼠标为中心，
  最细到月份刻度）、拖动红色年份滑块选年、拖动其他区域平移窗口、双击或
  「时间全览」复位；上方世界时代带 + 中国朝代带（可点击跳转）；**悬停事件
  圆点冒泡显示事件名与年月**，点圆点直接选中并定位地图；◀▶ 逐件大事；
  键盘 ←/→、空格。
- **月份定位**：史实月份可靠的事件（五四运动 1919年5月、七七事变 1937年7月、
  开国大典 1949年10月等约 60 条）在时间轴上按月精确落点，卡片与气泡同步
  显示年月。
- **事件标记**：朱砂（中国）/ 墨青（域外）；必知大事为印章方块 + 分类字
  （政/战/文/技/商/人）；同地事件自动散开；点击选中有朱砂光环。
- **「世界 / 中国」页签**：不仅切换地图视角，也是内容范围——中国页签下只显示
  中国史事件（地图标记、卡片、时间轴点亮同步过滤），不可用的区域筛选自动置灰。
- **教材出处**：每个事件标注统编版教材出处（初中《中国历史》七上~九下、
  《世界历史》九上九下、高中《中外历史纲要》上下册），按"册 + 主题"归类，
  具体课次以现行教材为准；课本外事件标注"课外拓展"。
- **模糊搜索**（顶栏，Ctrl+K 聚焦）：支持事件关键词（标题/描述/贴士/朝代标签，
  含子序列模糊匹配）、年份（"前221"、"1937年"）与朝代/时代名（"唐朝"）。下拉
  候选实时高亮，点击事件直达地图定位，点击朝代直接把时间轴缩放到该区间；
  ↑↓/Enter/Esc 键盘可用。
- **册页卡片**：事件详情（朝代、年代、区域、分类、儿童友好描述、趣味贴士、
  教材出处），点击卡片地图自动飞行定位。
- **筛选**：8 个区域 × 6 个分类书签 + 「只看大事」。
- **自动游览**：像翻连环画一样逐年推进（约 30 年/秒），随时暂停。

## 目录结构

```
index.html          页面骨架 + SVG 滤镜定义
css/style.css       全部古风样式
js/land.js          陆地轮廓数据（由 tools/prep_land.py 从 data/land110m.json 生成）
js/data.js          事件数据集 + 朝代表 + 世界时代表
js/sources.js       教材出处映射（SOURCES[id] → [教材, 主题]）
js/app.js           投影渲染、缩放平移、时间轴、交互
data/land110m.json  Natural Earth 110m land 原始 GeoJSON（留存）
tools/prep_land.py  预处理：取整/去重/内外环分离/去小岛
tools/build_single.py  打包单文件 HTML
```

## 数据 schema（js/data.js）

```js
{
  id: 'qin-unify',
  y: -221,            // 起始年，负数 = 公元前
  y2: 1949,           // 可选：结束年（长期事件如都江堰、科举）
  title: '秦统一六国',
  region: 'china',    // china|eastasia|southasia|westasia|europe|africa|americas|oceania
  cat: 'politics',    // politics|war|culture|tech|economy|figure
  imp: 3,             // 3=必知大事(印章标记) 2=重要 1=有趣
  lat: 34.33, lng: 108.71,
  tag: '秦',          // 朝代/文明标签
  desc: '……',         // 儿童友好的 1~2 句说明
  tip: '……'           // 小贴士
}
```

扩充事件只需在 `EVENTS` 数组里追加同构对象；朝代/时代带改 `DYNASTIES` /
`WORLD_ERAS`。未来外置为 JSON 或接数据库时，schema 保持不变。

## 地图投影

等距圆柱投影（经纬度线性映射），坐标区间：经 -180~180，纬 78 ~ -55。
数据坐标取整到 0.01°（约 1km），110m 精度适合全球概览。
